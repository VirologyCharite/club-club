Sequence versus sequence identity table

The table cells below show the nucleotide identity fraction for the sequences (like this for the best value in each row). The identity fraction numerator is the sum of the number of identical nucleotides plus the number of ambiguously matching nucleotides. The denominator is the length of the sequence for the row. Sequence gaps are not included when calculating their lengths.

Key to abbreviations:

  • L: sequence Length.
  • G: number of Gaps in sequence.
  • IM: Identical nucleotide Matches.
  • AM: Ambiguous nucleotide Matches.
  • GG: Gap/Gap matches (both sequences have gaps).
  • G?: Gap/Non-gap mismatches (one sequence has a gap).
  • NE: Non-equal nucleotide mismatches.
